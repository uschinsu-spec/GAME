# THƯ VIỆN ASSET MÔI TRƯỜNG TIÊN CẢNH (ASSETS/MAPS/COMMON)

Toàn bộ 90 asset môi trường tiên cảnh độ phân giải cao đã được chuẩn hóa điểm tiếp đất `0px` sát đáy (Bottom-Edge Touch) và căn giữa (Center Horizontal), sẵn sàng sử dụng cho mọi bản đồ (Thanh Vân Thôn, Bạch Ngọc Thành, U Hồn Cốc, Côn Lôn...).

---

## 1. Cấu Trúc Phân Loại (10 Danh Mục)

```text
assets/maps/common/
├── trees/           (9 cây)       - Cây cổ thụ, đào hoa, liễu rũ, tùng bách, tiên thụ
├── rocks/           (10 tảng đá)  - Vách đá, thạch nham, ụ đá rêu hoa, cụm linh thạch
├── plants/          (8 hoa cỏ)    - Bụi hoa mẫu đơn, cỏ đuôi chồn, bụi quả dại, linh thảo
├── lanterns/        (10 đèn)      - Đèn lồng gỗ, đèn đá rêu phong, trụ đèn treo, đèn miếu
├── fences_gates/    (13 rào/cổng) - Hàng rào tre/gỗ/hoa, cổng đền, cổng chùa, chuông trận môn
├── buildings/       (11 kiến trúc)- Nhà tranh, lầu ngọc, đình tạ ven nước, miếu Thổ Địa, miếu Phật, lò rèn
├── bridges_water/   (10 cầu/nước) - Cầu đá, cầu gỗ vòm, đầm hoa sen, bến gỗ, thác nước, dòng suối
├── props/           (10 vật dụng) - Xe chở dược liệu, vò linh tửu, thùng gỗ, bao tải, bếp lửa, sạp hàng, giếng nước
├── signs/           (7 bia đá)    - Bia Thái Cực Âm Dương, bia hoa anh đào, bảng cáo thị, cột mốc chỉ đường
└── magical/         (2 linh bảo)  - Lam ngọc linh tinh phát sáng, cột sáng thiên địa (Loot Beam)
```

## 3. Cách Gọi Dùng Trong Mã Nguồn Game (`game.js`)

Khi cấu hình bất kỳ bản đồ nào trong `MAP_CONFIGS`:
```javascript
// Ví dụ thêm cây phong lá vàng vào bản đồ:
MAP_CONFIGS.thanh_van_thon.trees.push({
  file: 'assets/maps/common/trees/tree_autumn_01.png',
  width: 3.8,
  height: 5.2
});

// Thêm công trình vào cảnh quan làng:
MAP_CONFIGS.thanh_van_thon.villageProps.push({
  file: 'assets/maps/common/buildings/house_herbal_01.png',
  x: 15, z: 12, width: 5.6, height: 5.2
});
```
