# Tu Tiên Chi Lộ — World Expansion v2

Babylon.js 2.5D mobile web game, designed for iPhone/Android and GitHub Pages.

## v2 systems
- Cảnh giới: Luyện Khí tầng 1–12; Trúc Cơ, Kết Đan, Nguyên Anh, Hóa Thần × Sơ/Trung/Hậu/Đỉnh Phong.
- Công pháp: Hoàng → Huyền → Địa → Thiên, hệ số sức mạnh tăng dần.
- 9 hệ skill: Kim, Hỏa, Thủy, Thổ, Mộc, Phong, Lôi, Kiếm, Đao; VFX đổi theo hệ.
- Đan dược, phù lục, pháp bảo Nhất → Ngũ phẩm theo cấp.
- 8 khu vực: thôn, man hoang, thành, tông môn, sa mạc, yêu vực, cấm địa, ma vực.
- Enemy level và chủng loại thay đổi theo khu vực; tinh anh + boss.
- Auto combat, joystick mobile, loot, equipment, pet, shop, daily, minimap, save localStorage, PWA/service worker.
- Sprite player + Ma Lang + Linh Hồ + Thạch Khôi + Ảnh Thú đã nằm trong assets/sprites2.

## Run
`python -m http.server 8080` rồi mở `http://localhost:8080`.

## GitHub Pages
Upload toàn bộ nội dung thư mục này vào repo, bật Settings → Pages → Deploy from branch.
